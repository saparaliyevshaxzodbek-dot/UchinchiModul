# C# Module 3 — Generics, Data Structures and ASP.NET Core Web API

The third module: from generic collections written by hand to the first REST APIs with authentication.

## What's inside

- Own generic collections: `MyList` (`IMyList`), `MyStack`, `MyQueue`, `Dictionary`, linked list `Node`/`NodeService`, `Pair`, `Range`, `Box`, `Wrapper`
- CRUD Web APIs (`CRUD.Api`) with controllers, services and repositories
- `SocialMedia` API: users and posts, registration and login with JWT (`AuthService`, `TokenService`), repositories and EF Core `AppDBContext`
- Practice APIs: `CRM.Api`, `MyMovie.Api`, `NewProject.Api`

## Tech

C# · ASP.NET Core Web API · EF Core · JWT · Swagger

## Run

Requires the .NET SDK.

```bash
cd 2chiDars/src/SocialMedia
dotnet run
```
